# 移步到位 · 导航到最美的拍照机位

百度地图开发者创作大赛参赛作品。

把导航的终点从“地点”修到“视角”：在百度地图上画出每个机位的取景扇形和太阳方向，按光线条件编排路线，用步行路线规划带你到附近，再用一步一图的路书和指南针带你站到位；到了之后叠加参考画面复刻同款、打卡、生成对比图，也可以上传自己发现的机位。

- 一个机位 = 空间里的一个点 + 一个朝向 + 一段时间切片
- 每一次打卡，都是对这个世界的一次巡礼

## 用到的百度地图能力
百度地图 JavaScript API GL：地图与个性化底图、标注与覆盖物、步行路线规划、浏览器定位（公交路线规划、地点检索、逆地理编码陆续接入）。

## 本地运行
用浏览器打开 `index.html` 即可。在 `config.js` 中填入百度地图浏览器端密钥（AK）后显示真实地图；未填写时为离线预览模式。
